# 🌐 SimpleToDo（React / JavaScript / HTML / CSS）

## 📘 概要
React / JavaScript を用いて開発した Web アプリケーションです。  
シンプルなToDoアプリを学習目的で作成しました。

---

## 🛠 開発環境
| 項目 | 内容 |
|------|------|
| 言語 | JavaScript |
| フレームワーク | React |
| データベース | Local Storage |
| ビルドツール | Vite |
| IDE | VS Code |
| バージョン管理 | Git / GitHub |
| OS | macOS / Windows |

---

## 🧩 機能一覧
| カテゴリ | 内容 |
|------------|------|
| 入力欄| タスクを入力 |
| 追加ボタン | フォーム入力によるタスクの追加 |
| タスク表示 | タスクの表示と完了と削除ボタン |
| 完了時 | 消すのではなく何を完了したのかわかるように横線表示・未完了に戻すボタンも配置 |
